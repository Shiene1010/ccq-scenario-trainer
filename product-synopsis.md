# CCQ Scenario Trainer - Product Synopsis

## 🎯 Product Goal
Help English learners master grammar by answering simple CCQ questions (Yes/No, short answers) based on realistic scenarios built around target expressions.

## 👥 Target Users
- ESL teachers creating CCQ practice materials
- English learners practicing grammar comprehension
- iOS app developers (you) building language learning tools

## 📱 Core User Journey (MVP)
1.	Target Expression: “I wish I might’ve taken a taxi last night.”
	2.	Scenario: Short story/illustration showing the context
	3.	3-5 CCQs: “Did he take a taxi? → No” “Does he regret it now? → Yes”
	4.	User answers → Instant feedback → Score + explanation

## 🎮 Key Features (Milestone 1)
- **Target Expression Display** - Grammar focus sentence
- **Scenario Context** - Short story/image (100 words max)
- **CCQ Questions** - 3-5 simple yes/no or choice questions
- **Answer Input** - Buttons or short text field
- **Immediate Feedback** - Correct/Incorrect + explanation
- **Progress Score** - Session completion percentage

## ✅ Success Criteria (Milestone 1)
- User completes one full cycle in <2 minutes
- 90% CCQ answer accuracy for validated questions
- iOS SwiftUI native app, works on iPhone 14+
- Dark/Light mode support
- Offline first (local data)

## 🚨 Known Risks
- CCQs becoming too complex instead of simple Yes/No
- Scenario context confusing the grammar point
- Inconsistent answer validation logic
