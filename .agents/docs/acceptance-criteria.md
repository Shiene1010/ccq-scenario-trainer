# Acceptance Criteria — Milestone 1 (MVP)

## 핵심 성공 조건 (검증 가능한 항목)
1. 전체 플로우
   - 사용자가 타겟 문장 확인 → 시나리오 읽기 → 3–5개의 CCQ에 답변 → 즉시 피드백을 받는 한 사이클을 완료할 수 있어야 한다.
   - 사이클 완료 시간: 평균 사용자 기준 2분 이내.

2. CCQ 정답률
   - 사전 검증된 CCQ 세트에서 시뮬레이션 테스트 중 자동 채점 정답률이 90% 이상이어야 한다.

3. 플랫폼/환경
   - iOS SwiftUI 앱으로 빌드되어 iPhone 14 시뮬레이터에서 실행 가능해야 한다.
   - 다크/라이트 모드에서 UI가 무너지지 않아야 한다.
   - 네트워크 없음(오프라인) 상태에서도 최근 세션 데이터(예: 문제/점수)를 로컬에 저장하고 로드할 수 있어야 한다.

4. UX & 접근성
   - CCQ 입력은 버튼(Yes/No) 또는 1줄 텍스트로 가능해야 하며, 버튼은 터치 영역이 iOS 권장 기준 이상이어야 한다.
   - 즉시 피드백(정오 표기 + 간단 설명)이 답변 직후 1초 이내에 표시되어야 한다.
   - 최소한 VoiceOver에서 문장과 질문을 읽을 수 있어야 한다(레이블링).

5. 데이터/검증
   - CCQ마다 정답(yes/no/choice)을 명시한 메타데이터가 있어야 하며, 앱은 이를 기반으로 자동 채점한다.
   - 검증되지 않은(초안) CCQ는 내부 표시(예: 태그 `draft`)가 있어 QA 과정에서 걸러진다.

## 수용 테스트 케이스 (예시)
- T1: 정상 플로우 — 주어진 3개 CCQ에 모두 정답으로 답했을 때 점수 3/3, 피드백과 설명 노출.
- T2: 오프라인 — 네트워크 차단 후에도 저장된 세션 불러오기 및 재시작 가능.
- T3: 다크 모드 — 다크 모드에서 텍스트 가독성 검증(대비도).
- T4: 장애 케이스 — CCQ 메타데이터 누락 시 사용자에게 오류 메시지 및 관리자 리포트 로그 남김.
